# labelstudio-term-variation
This repository contains an R pipeline for processing annotations of intratextual terminological variation made in Label Studio. It reads the JSON export of each annotated text, reconstructs terms whose constituents are not contiguous (using the parentID field), pairs each variant with its base term, checks the direction of relations, and removes duplicates while keeping occurrence counts. The output is three CSV files ready for analysis. The pipeline was developed for the annotation of research articles in Earth and Planetary Sciences, but the typology and code can be adapted to other domains.
